The Confront — Changelog
Version 0.5 | November 24, 2026 at 10:53 (America/Sao_Paulo)

- NPCs: removed the separate class-selection step; the class selected in the form is saved to the NPC file. Added the Spirits class.
- Weapons: close and distant firing sounds, projectile speed, and spread follow each individual .wpm configuration.
- Menus and maps: removed the store and map selector from the main menu. Stores are now placed on maps through the builder and opened at their location.
- TravelPoint: added a form for source and destination XYZ bounds and destination map; Alt+Enter transfers only from a valid area and enforces level/resurrection locks.
- Transitions: audio sources from the previous map are stopped and the new map's sounds are refreshed.
- Translations: TravelPoint form and messages, map store placement, and Spirits class are translated in Portuguese, English, and Spanish.
- Updater: synchronized the manifest with published versions and files, verified package sizes, and removed the duplicate maps configuration entry.
- Cleanup: removed dead/duplicate code identified during review, including the duplicate dw.nvgt source and obsolete updater helpers.
