The Confront — Changelog
Version 0.6 | November 24, 2026 at 11:16 (America/Sao_Paulo)

- Stores: each storefront now contains its own categories; Enter opens a placed store, arrow keys move through its categories, and Tab opens the selected category's items.
- TravelPoint: Alt+Enter checks the current position silently when no valid travel point is present.
- Updater: before confirmation, it displays this version's changes in a native multiline field; game, content, map, and sound packages use separate files and validation.
- Installation: encrypted content and map files are validated and staged before replacement; the previous file is restored if installation fails.
- Website: refreshed the home and projects pages and added a The Confront overview and manual with version 0.6 downloads.
- Distribution: full packages are prepared without source code or player save data.
